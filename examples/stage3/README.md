## 复现与边界

```powershell
python -m pytest -q --junitxml=examples/stage3/tests.xml
python scripts/verify_stage3.py
python scripts/verify_stage3.py T05 T06B
python scripts/run_agent.py --mode mock --question "报销期限多久？" --format text
```

真实脚本会调用模型，结果存在波动；每次新建目录。验收预期和用例编号不传给模型。自动检查只确认状态、来源和结构，不能证明引文语义支持全部答案。冲突提示仅覆盖同范围同句式数值差异，其余依赖模型识别；替代关键词检查也不能代替语义核验。

本阶段覆盖六项核心验收类型，但 T04 另外两种改写、完整资料替换对比、检索改进实验和最终提交整理留待阶段四。T12 等用例单次成功不代表任意版本冲突都能正确消解。
